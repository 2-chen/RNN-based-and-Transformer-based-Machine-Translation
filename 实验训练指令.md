# 实验训练指令

本文档提供了各种实验的训练指令，方便快速执行。

## 1. 相对位置编码实验

### 方法1：直接使用训练脚本
```bash
python src/train_transformer.py \
    --config configs/transformer_config.yaml \
    --pos_encoding relative \
    --save_dir checkpoints/transformer_pos_relative \
    --epochs 10
```

### 方法2：使用实验脚本
```bash
python run_experiments.py --experiment transformer_pos_encoding
```

## 5. RNN解码策略对比

### 使用评估脚本（推荐）
```bash
# 使用已训练好的模型进行解码策略对比
python evaluate_rnn_decoding.py \
    --model_path checkpoints/rnn_best.pt \
    --valid_file data/valid.jsonl \
    --test_file data/test.jsonl \
    --beam_size 5 \
    --output_file checkpoints/rnn_decoding_comparison.json
```

### 使用训练脚本
```bash
# 步骤1：训练模型（如果还没有）
python src/train_rnn.py \
    --config configs/rnn_config.yaml \
    --epochs 10 \
    --save_dir checkpoints/rnn_baseline

# 步骤2：使用Greedy解码评估
python src/train_rnn.py \
    --config configs/rnn_config.yaml \
    --decode_method greedy \
    --save_dir checkpoints/rnn_baseline

# 步骤3：使用Beam Search解码评估
python src/train_rnn.py \
    --config configs/rnn_config.yaml \
    --decode_method beam \
    --beam_size 5 \
    --save_dir checkpoints/rnn_baseline
```

## 注意事项

1. **GPU内存**：大模型（d_model=1024）和大batch size（256）需要较大的GPU内存，如果内存不足，可以减小batch size或使用梯度累积。

2. **训练时间**：不同配置的训练时间差异很大：
   - 小模型（512/4层）：约1-2小时/epoch
   - 中等模型（768/6层）：约2-3小时/epoch
   - 大模型（1024/6层）：约3-4小时/epoch

3. **结果查看**：训练完成后，结果会保存在对应的checkpoint目录下的`transformer_results.json`文件中。

4. **继续训练**：如果训练中断，可以直接重新运行相同的命令，脚本会自动加载已有检查点继续训练。
