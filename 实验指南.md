# 完整对比实验指南

本指南详细说明如何运行所有要求的对比实验。

## 实验概览

根据作业要求，需要完成以下对比实验：

### RNN模型实验
1. **注意力机制对比**：dot-product vs multiplicative vs additive
2. **训练策略对比**：Teacher Forcing vs Free Running
3. **解码策略对比**：Greedy vs Beam Search

### Transformer模型实验
1. **位置编码对比**：absolute vs relative
2. **归一化方法对比**：LayerNorm vs RMSNorm
3. **超参数敏感性分析**：batch size, learning rate, model scale

## 实验结果收集和分析

### 1. 收集结果

所有实验结果会自动保存到 `checkpoints/*_results.json` 文件中。

### 2. 创建对比表格

可以使用以下Python脚本分析结果：

```python
import json
import os
from pathlib import Path

def analyze_experiments():
    """分析所有实验结果"""
    results = {}
    
    # 收集所有结果文件
    checkpoint_dir = Path("checkpoints")
    for result_file in checkpoint_dir.glob("*_results.json"):
        with open(result_file, 'r') as f:
            data = json.load(f)
            model_name = result_file.stem.replace("_results", "")
            results[model_name] = data
    
    # 创建对比表格
    print("="*80)
    print("实验结果对比")
    print("="*80)
    
    for name, data in results.items():
        print(f"\n{name}:")
        print(f"  Valid BLEU: {data.get('best_valid_bleu', 'N/A'):.4f}")
        print(f"  Test BLEU: {data.get('test_bleu', 'N/A'):.4f}")
        print(f"  配置: {data.get('args', {})}")
    
    # 保存汇总结果
    with open("experiment_results/summary.json", 'w') as f:
        json.dump(results, f, indent=2, ensure_ascii=False)

if __name__ == '__main__':
    analyze_experiments()
```

### 3. 可视化结果

可以使用matplotlib创建可视化图表：

```python
import matplotlib.pyplot as plt
import json

def plot_comparison(results_file, metric='test_bleu'):
    """绘制对比图表"""
    with open(results_file, 'r') as f:
        results = json.load(f)
    
    names = []
    scores = []
    
    for name, data in results.items():
        names.append(name)
        scores.append(data.get(metric, 0))
    
    plt.figure(figsize=(10, 6))
    plt.bar(names, scores)
    plt.title(f'{metric} Comparison')
    plt.ylabel('BLEU Score')
    plt.xticks(rotation=45, ha='right')
    plt.tight_layout()
    plt.savefig(f'experiment_results/{metric}_comparison.png')
    plt.show()
```

## 实验时间估算

根据你的计算资源，实验时间大致如下：

| 实验类型 | 单个实验时间 | 总实验数 | 总时间估算 |
|---------|------------|---------|-----------|
| RNN注意力机制 | 2-4小时 | 3 | 6-12小时 |
| RNN训练策略 | 2-4小时 | 2 | 4-8小时 |
| RNN解码策略 | 0.5小时 | 2 | 1小时 |
| Transformer位置编码 | 4-8小时 | 2 | 8-16小时 |
| Transformer归一化 | 4-8小时 | 2 | 8-16小时 |
| Transformer超参数 | 2-4小时 | 11 | 22-44小时 |

**总计：约49-97小时**（如果使用GPU）

### 优化建议

1. **减少epoch数**：实验阶段可以用5-10个epoch，完整训练时再用更多
2. **使用小数据集**：先用train_10k.jsonl快速验证，再用train_100k.jsonl
3. **并行运行**：如果有多个GPU，可以同时运行多个实验
4. **分批进行**：不需要一次性完成所有实验，可以分批进行
